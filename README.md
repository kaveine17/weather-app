# Weather App

Небольшое Vue-приложение для просмотра прогноза погоды по городу. В интерфейсе можно сменить город, посмотреть 3-дневный прогноз и увидеть основные параметры: влажность, облачность и скорость ветра.

## Что умеет приложение

- Отображает текущую погоду по выбранному городу
- Показывает прогноз на 3 дня
- Позволяет переключаться между днями
- Отображает основные показатели погоды
- Поддерживает адаптивный интерфейс под мобильные устройства
- Использует API сервиса WeatherAPI

## Требования

- Node.js 18+
- npm или yarn

## Установка

1. Клонируйте репозиторий:

```bash
git clone <URL_репозитория>
cd weather-app
```

2. Установите зависимости:

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

После этого приложение будет доступно в браузере по адресу, который покажет Vite (обычно `http://localhost:5173`).

## Сборка проекта

```bash
npm run build
```

Готовая сборка будет лежать в папке `dist/`.

## Примечание по API

В текущей версии ключ доступа к WeatherAPI используется напрямую в файле `src/App.vue`.
Для продакшн-использования лучше вынести его в переменные окружения и хранить отдельно от исходного кода.

## Пример использования

- Откройте приложение
- Нажмите кнопку «Изменить город»
- Введите название города и сохраните
- Оцените прогноз на 3 дня и основные погодные показатели
